# Krudex

QR ordering for restaurants and canteens: guests scan, order and pay from the table; kitchens and floors run from live screens.

```bash
pnpm install
pnpm dev            # http://localhost:3000, component preview at /preview
pnpm lint && pnpm typecheck && pnpm test
pnpm e2e            # Playwright (uses installed Chrome locally)
```

Specs: `docs/`. Build guide: `AGENTS.md`. Decisions: `docs/decisions.md`.
